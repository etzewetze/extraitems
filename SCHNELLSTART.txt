ExtraItems 0.2.1 — Schnellstart

1. Server stoppen.
2. ExtraItems-0.2.1.jar nach plugins/ kopieren; alte ExtraItems-JAR entfernen.
3. Server starten.
4. Standardmäßig nutzt das Plugin:
     resource-pack.mode: self-host
     resource-pack.self-host.public-host: auto
     resource-pack.self-host.port: 8123
5. TCP-Port 8123 beim Hoster/Firewall/Router freigeben.
6. Als OP beitreten und /ei status ausführen.
7. Die angezeigte Pack-URL von einem anderen Rechner testen.
8. Mit einem Nicht-OP-Spieler Paket, Rechte, Pflanzen und Rezepte prüfen.

Wichtig:
- localhost funktioniert nur auf demselben Rechner wie der Minecraft-Client.
- public-host: auto benutzt automatisch die Adresse, mit der der Spieler beitritt.
- Vanilla benötigt trotzdem einen erreichbaren HTTP(S)-Endpunkt.
- Wenn kein zusätzlicher Port möglich ist: mode: external und eine direkte HTTPS-ZIP-URL verwenden.
- Nur zum Testen ohne Pack: required: false und mode: disabled.
- Bei einer fehlerhaften Pack-Konfiguration haben Administratoren standardmäßig Notfallzugang.

Neue Item-Struktur:
  plugins/ExtraItems/items.yml
  plugins/ExtraItems/items/tomato/item.yml
  plugins/ExtraItems/items/tomato/crop.yml
  plugins/ExtraItems/items/tomato_seeds/item.yml
  plugins/ExtraItems/items/tomato_seeds/recipes/*.yml

Beim Update von 0.1.0 wird die alte items.yml als items.legacy.yml gesichert
und automatisch in einzelne Dateien aufgeteilt.

Admin-Befehle:
  /ei status
  /ei pack
  /ei give SPIELERNAME tomato_seeds 16
  /ei give SPIELERNAME tomato 16

LuckPerms:
  lp group farmer permission set extraitems.plant.tomato true
  lp group farmer permission set extraitems.craft.tomato_seeds true

Tomaten essen und reife Pflanzen ernten sind ohne diese Rechte erlaubt.
Vor Updates Welten und plugins/ExtraItems sichern. Kein /reload verwenden.
